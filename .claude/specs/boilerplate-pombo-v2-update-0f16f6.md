## 1. Goal

Bring this boilerplate to the same standard the `pombo` repository reached in its last four rounds (Claude workflow parity with cuidda → backend clean-architecture hardening → Chakra v3 standardization + `@pombo/theme` + styleguide → project-structure/deploy standardization), so that a project bootstrapped from here starts with: the newest agent/skill workflow (`.claude/**` + `CLAUDE.md`), a module-first backend with a composable config, a graceful lifecycle, guards for the recurring bug classes, a single multi-stage image and CI; a web app with a design-system package, official Chakra v3 snippets, a DEV-only styleguide with visual regression and no dead code; and deploy/config files that describe exactly the app that exists. Everything stays **generic**: no WhatsApp/devices/Baileys vocabulary, the boilerplate's own domain (`auth` + `user` as the reference module), ports `3000`/`3333`, Node 22, and its newer toolchain (Vite 7, Vitest 3, ESLint 9, TS 5.8) are kept.
